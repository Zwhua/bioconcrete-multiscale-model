# Curated Public Data

No curated observations are currently committed because the selected raw
datasets have not been downloaded and manually reviewed. This directory stores
templates and applicability metadata, not substitute observations.

Formal files, once reviewed, are named:

- `transet_18clsu02_observations.csv`
- `transet_18clsu02_dictionary.csv`
- `marine_external_observations.csv`
- `marine_external_dictionary.csv`

Raw publisher files remain Git-ignored. A dictionary row with
`reviewer_status=approved` is required for every included normalized field.
