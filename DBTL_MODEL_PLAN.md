# Prospective Model DBTL Loop

**Status:** Model-informed experimental plan. Awaiting wet-lab execution. Not
experimentally validated.

## Design

Compare crack width, complete repair-agent dose, wetting regime, aggregate
activity, response delay and basal leakage. Use an abiotic C-S-H control and
measure CaCO3 mass separately from closure.

## Build

This repository does not specify or infer biological construction steps. The
model exposes only an anonymous aggregate activity interface and material-dose
conditions suitable for experiment planning.

## Test

The minimum plan measures closure, CaCO3 mass, substrate and oxygen at matched
time points. Success and failure thresholds are frozen in
`PROSPECTIVE_PREDICTIONS.yml` before team observations are available.

## Learn

Update only parameters constrained by the corresponding measurements. Retain
failed predictions, revise the documented model structure when needed, and
create a new version rather than rewriting historical results.

No completed DBTL cycle is claimed. The first team-data update can begin only
after traceable wet-lab observations are added and reviewed.
